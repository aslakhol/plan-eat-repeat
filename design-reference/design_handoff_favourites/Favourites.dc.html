5Favourites — the mark and where it lives

A favourite is a single explicit flag, so it only needs a single mark. One small terracotta heart, always trailing the dinner name, everywhere a dinner is named. It is only ever tappable in one place — the dinner sheet header — so a heart in a list is safe to read past. 5a is the heart; 5b is the same set drawn with a star, for comparison.
